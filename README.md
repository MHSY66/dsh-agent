# dsh-agent

A coding agent that works on this repository when you ask it to from GitHub.

## Usage

Mention the agent's account, [@MHSYXH](https://github.com/MHSYXH), in an issue or an issue comment and describe what you need:

> @MHSYXH Add a usage example to the README.

From an account allowed to request work for this repository, the agent will:

1. Acknowledge the request in the same conversation.
2. Work on a branch and open a pull request.
3. Report back with the pull request link.

A person reviews and merges the pull request; the agent never merges its own work.
